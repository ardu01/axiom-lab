# AXIOM Lab — iPhone PWA (alpha)

Open the GitHub Pages URL in Safari and choose Share → Add to Home Screen.

This is an early **working prototype**, not the requested complete engineering product. It supports local saving, draggable schematic symbols, pin connections, a narrowly limited resistive DC calculation, and a basic 3D primitive canvas. STL currently supports cubes only. It does **not** provide a general circuit solver, SPICE, full CAD, or accurate LED simulation. Offline caching uses a service worker.

No npm, server, account, or build step is required to use this standalone deployment. The original React/Three.js source package has not been deployed here. Future releases should replace this prototype with the tested modular application.
